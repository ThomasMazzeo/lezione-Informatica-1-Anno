Fase 1: Il Problema

Il "Doppio Controllo"

L'if normale controlla una sola cosa. Ma cosa succede se per essere promosso devi avere sia il voto alto sia poche assenze?

Gli "if" Annidati (Scomodi)

Siamo costretti a mettere un `if` dentro un altro `if`. Il codice si sposta sempre più a destra, diventando difficile da leggere e lungo da scrivere.

scuola_vecchia.cpp
#include <iostream>

int main() {
int voto = 7;
int assenze = 5;

if (voto >= 6) { // Primo controllo
if (assenze <= 10) { // Secondo controllo
std::cout << "Promosso!";
}
}

return 0;
}
Fase 2: La Soluzione

I Superpoteri Logici

Per evitare l'incubo degli `if` dentro gli `if`, il C++ ci regala tre simboli speciali che uniscono le condizioni in una sola riga.

&&

AND (E)

Tutte le condizioni devono essere VERE.

"Esco SE ho finito i compiti && non piove."

Basta che una sia falsa, e il blocco viene saltato.

||

OR (OPPURE)

Basta che UNA SOLA condizione sia VERA.

"Bevo acqua SE ho sete || fa molto caldo."

Si blocca solo se sono tutte false.

!

NOT (NON)

Inverte la realtà. Trasforma il Vero in Falso e viceversa.

"Gioco !(se è ora di cena)."

In Pratica

L'Unione fa la Forza

Guarda come si trasforma il codice di prima usando l'operatore &&. Ora è pulito, leggibile e compatto.

scuola_nuova.cpp
#include <iostream>

int main() {
int voto = 7, assenze = 5;

if (voto >= 6 && assenze <= 10) {
std::cout << "Promosso!";
} else {
std::cout << "Bocciato o Rimandato.";
}

return 0;
}

Fase 3: Un nuovo problema

L'Incubo dei Menu

Immagina di creare il menu iniziale di un videogioco. Ci sono 4 opzioni. Se usi solo la struttura else if, crei una scala lunghissima che il computer deve scendere gradino per gradino.

La Cascata Lenta

Se l'utente digita "4", il computer deve comunque controllare se è 1, poi se è 2, poi se è 3... uno spreco di tempo e di righe di codice.

menu_lento.cpp
int scelta = 4;

if (scelta == 1) {
std::cout << "Nuova Partita";
} else if (scelta == 2) {
std::cout << "Carica";
} else if (scelta == 3) {
std::cout << "Opzioni";
} else if (scelta == 4) {
std::cout << "Esci";
}
La Soluzione Elegante

Lo Scambio Ferroviario

Entra in scena lo switch

Pensa allo switch come a uno scambio dei binari. Prende un valore in ingresso e devia istantaneamente il treno sul binario corretto, senza dover controllare tutti gli altri ad uno ad uno.

Anatomia

Smontiamo il Menu

menu_veloce.cpp
#include <iostream>
int main() {
int scelta = 2;

switch (scelta) {
case 1:
std::cout << "Nuova Partita"; break;
case 2:
std::cout << "Carica Partita"; break;
default:
std::cout << "Errore!";
}
return 0;
}

case (Il Binario)

Ogni case è una destinazione. Se scelta vale 2, il C++ salta magicamente a case 2:.

break; (Il Freno)

REGOLA D'ORO.

Senza il break, il treno non si ferma e "schianta" leggendo anche i case sottostanti!

default: (Il Paracadute)

L'equivalente dell'else. Gestisce tutto ciò che non è previsto (es. l'utente preme "9").
